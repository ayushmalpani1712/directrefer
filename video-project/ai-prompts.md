## General Tips for AI Video Generation

### Aspect Ratio
Always specify **16:9** for YouTube videos.

### Style Keywords
Add these for consistent results:
- `cinematic`
- `professional`
- `corporate`
- `clean`
- `minimalist`
- `modern`

### Quality Boosters
Include these phrases:
- `high detail`
- `4K quality`
- `professional lighting`
- `sharp focus`
- `studio quality`

### Color Grading
Specify colors for brand consistency:
- `blue and green color grading`
- `corporate color palette`
- `deep blue and accent green`

### Duration Recommendations
- **Runway ML:** 4-16 seconds per generation
- **Pika Labs:** 3-4 seconds per generation
- **Stable Video Diffusion:** 4-8 seconds per generation

### Post-Production
After generating clips:
1. Import to video editor (DaVinci Resolve, Premiere Pro)
2. Add voiceover
3. Add background music
4. Add text overlays
5. Add transitions
6. Color grade for consistency
7. Export at 1080p, 30fps

---

## Recommended Workflow

1. **Generate clips** using AI tools (2-3 variations each)
2. **Select best clips** for each scene
3. **Import to editor** and arrange on timeline
4. **Add voiceover** (record or AI-generated)
5. **Add music** (YouTube Audio Library for free)
6. **Add text overlays** from script document
7. **Add transitions** between scenes
8. **Color grade** for consistency
9. **Export** and upload to YouTube
